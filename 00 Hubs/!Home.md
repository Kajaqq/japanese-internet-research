# Home

A research vault on early Japanese (and Japanese-influenced) internet culture: the anonymous textboards and imageboards of the late 1990s–2000s, Niconico, and the internet memes that grew out of them — above all Kasane Teto.

## Topic hubs
In rough chronological order of the communities themselves:

1. [[Ayashii World Hub|Ayashii World]] — the first large-scale anonymous textboard in Japan (1996–)
2. [[2channel Hub|2channel]] — Hiroyuki's textboard, 1999–; now 5channel
3. [[Futaba Channel Hub|Futaba Channel]] — the image board that grew alongside 2channel (2001–)
4. [[4chan Hub|4chan]] — the English-language copy of Futaba (2003–)
5. [[Niconico Hub|Niconico]] — the video site 2channel users flocked to (2006–)
6. [[Kasane Teto Hub|Kasane Teto]] — the 2008 April Fools' fake Vocaloid from 2channel's VIP board, plus UTAU

## Lineage at a glance

## Note types in this vault
Every note has a `type` property:

| type | meaning |
| --- | --- |
| `clipping` | Website content saved as-is (English or Japanese original) |
| `translation` | Japanese website content (mostly Nicopedia) translated to English |
| `ai-summary` | LLM-generated — only the notes in `2chan/LLM Generated/`; verify against a source |
| `link-list` | List of external links |
| `hub` | Topic overview (these notes) |

Each note's `topics` property links back to its hub, so the **Backlinks** pane on any hub shows every note filed under it.
