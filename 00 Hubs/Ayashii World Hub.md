# Ayashii World

**Ayashii World** (あやしいわーるど) was the first large-scale anonymous textboard in Japan, run by **Shiba**. It set up the anonymous posting and in-joke/meme culture later inherited by Amezou World, 2channel and, through Futaba Channel, 4chan. Constant server crashes led to threats against Shiba, and he closed the original site in 1998. Its users scattered and started clone boards, the best known being **Amezou World** (from June 9, 1998).
